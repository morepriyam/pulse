# Security Policy

## Supported Versions

Only the latest release of Pulse receives security fixes.

| Version | Supported |
| ------- | --------- |
| 2.x     | ✅        |
| < 2.0   | ❌        |

## Reporting a Vulnerability

Please **do not** open a public GitHub issue for security vulnerabilities.

Report privately via GitHub's [private vulnerability reporting](https://github.com/mieweb/pulse/security/advisories/new), or email [info@mieweb.com](mailto:info@mieweb.com).

We'll acknowledge your report within 3 business days and keep you updated until it's resolved. Issues in [PulseVault](https://github.com/mieweb/pulsevault) or upstream dependencies should be reported to those projects directly — but if you're not sure where an issue belongs, report it to us and we'll help route it.
